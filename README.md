# NIME Conference Cookbook

This online book is a semi-public working document for the organization of the [NIME conference](http://www.nime.org) series. It contains guides and information for the various track chairs, 

The source code can be found and edited in this GitHub Repository: <https://github.com/NIME-conference/NIME-cookbook/>

If you want comment on anything or get write access to the Cookbook, please get in touch with the [chair of the Steering Committee](http://people.uio.no/alexanje).

## Contributing
To contribute to the NIME cookbook, please fork this repo and create a pull request. If you are not familiar with GitHub, send your proposed modifications by email to the NIME Board members-at-large ([contact details here](https://nime.org/board/)).

## Building this website locally
If you want to preview your changes, you will need to have have `node` and `npm` installed; follow [these instructions](https://nodejs.org/en/download) to install them. 

Then you will need to install the necessary site dependencies:

```bash
npm install -D
```
To build the page and preview the site with your local changes:

```bash
npm run build
```

This site is built and published with GitHub actions. Once you are happy with your changes, push them to your fork of this repo and open a pull request to the `main` branch of [https://github.com/NIME-conference/NIME-cookbook](https://github.com/NIME-conference/NIME-cookbook).
